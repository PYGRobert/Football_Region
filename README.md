# 足球生涯：抉择与传承 v2.0

## 版本说明

v2.0 是重大版本更新，核心变更是**事件系统全面重构**。旧有的扁平 chain 链式系统被替换为三层系列事件体系（树状/线性/伏笔），同时修复了 v1.5 的 7 个显示与动画 Bug。

---

## v2.0 事件系统

### 三类系列事件

| 类型 | 标识 | 结构 | 结局数量 | 设计意图 |
|------|------|------|----------|----------|
| **树状系列** | `tree` | 3步 → 4叶子结局 | 4 | 分支叙事，隐藏数值，`?` 展示 |
| **线性 counter** | `linear` | N步 → 成功/失败 | 2 | 长因果叙事，累计正确选项 |
| **线性 keynode** | `linear` | N步 → 成功/失败(提前终止) | 2 | 关键决策点，选错立即失败 |
| **伏笔系列** | `foreshadow` | 2-3步 | 逐步升级 | 日常钩子触发，数值递增 |

### 调度优先级

```
进行中系列 (继续) > 伏笔钩子触发 > 随机启动树状/线性 > 日常事件
```

- 系列事件中间不穿插日常事件（子弹时间）
- 触发前做赛季容量检查，不跨赛季
- 每个系列每生涯只触发一次
- 树状系列每赛季最多 2 个，线性每赛季最多 1 个
- 伏笔系列仅通过钩子触发，不参与随机抽取

### 钩子系统

日常事件可携带 `hook` 字段推进伏笔计数器：

```js
{
  id: 'locker_chat',
  hook: { counterKey: 'locker_tension' },  // 无论选哪边都 +1
  effectsLeft:  { team: 2 },
  effectsRight: { team: -1, ability: 2 },
  ...
}
```

计数器达到阈值时自动触发对应伏笔系列。

## v2.0 视觉改动

### +/- 符号覆盖层

| 旧 (v1.5) | 新 (v2.0) |
|-----------|-----------|
| 圆点大小二档 (small/large) | +/++/+++/++++/+++++ 五档 |
| 单列纵向 | 两行两列，紧凑排列 |
| 声望点阵区域 | 声望统一用 +/- 行 |

效果值映射：

| 绝对值 | 符号 |
|--------|------|
| 1–3 | `+` / `-` |
| 4–6 | `++` / `--` |
| 7–9 | `+++` / `---` |
| 10–12 | `++++` / `----` |
| 13+ | `+++++` / `-----` |

树状系列隐藏模式：受影响属性显示 `?`，不影响属性显示 `·`。

### 系列进度条

卡片顶部增加进度标识：
```
┌──────────────────────────────┐
│ 世界杯征途   ●●●○○   3/5  ✓✓✗│
│           [卡片内容]          │
└──────────────────────────────┘
```

### 时间线赛季分割线

旧有的 "第X赛季结束" 条目改为优雅的分割线：
```
──── 第 2 赛季 ────
○ 20岁 · 打进生涯首球
○ 21岁 · 执教之路：战术大师

──── 第 3 赛季 ────
○ 22岁 · 转会豪门
```

## 使用方法

1. **新游戏**：直接打开 `index.html`
2. **继续游戏**：有存档时弹出对话框选择
3. **操作方式**：
   - 鼠标：拖拽卡片左右滑动
   - 触屏：滑动卡片
   - 键盘：← → 或 A D 键
   - 特殊结局引导卡片：**点击**触发翻牌
4. **调试面板**：按 `` ` `` (反引号) 键切换
