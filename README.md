## 🎨 卡片视觉分类系统 (v1.5)

### 设计原则

| 卡片类型 | 视觉风格 | 触发条件 |
|----------|----------|----------|
| **日常事件** | 温暖米白色 `#fefdfb→#f5f3ed` | 无 `color` 属性的事件 |
| **金色特殊事件** | 皇家暗金 `#1c1700→#2a2000` | `color:"gold"` — 世界杯/欧冠/冠军赛事 |
| **靛蓝特殊事件** | 深邃星空 `#0d1b2a→#1a1a3e` | `color:"special"` — 转会/德比/教练/财务/传奇链 |
| **暗红特殊事件** | 压迫暗夜 `#1a0a0a→#0a0a0a` | `color:"dark"` — 更衣室/伤病/负面事件 |

### 日常事件 (米白色)

日常随机事件使用统一的温暖米白色卡片，无边框设计，给人轻松、日常的感觉：
- 背景：`linear-gradient(180deg, #fefdfb 0%, #f5f3ed 100%)`
- 标题：灰色 `#999`
- 正文：深色 `#1a1a2e`

### 特殊事件 (独立色彩)

**金色 — 世界杯/欧冠/冠军赛事**
- 背景：深金黑 `linear-gradient(160deg, #1c1700, #2a2000, #1a1500)`
- 标题：金色 `rgba(201,168,76,0.9)`
- 正文：暖白 `rgba(255,248,230,0.95)`
- 边框：金色半透明 `rgba(201,168,76,0.2)`
- 图标阴影：金色光晕

**靛蓝 — 转会/德比/教练/财务/传奇链式事件**
- 背景：深靛蓝 `linear-gradient(160deg, #0d1b2a, #1a1a3e, #0d1b2a)`
- 标题：蓝色 `rgba(120,170,255,0.8)`
- 正文：冷白 `rgba(220,230,255,0.95)`
- 边框：蓝色半透明 `rgba(80,120,200,0.15)`
- 图标阴影：蓝色光晕

**暗红 — 更衣室/伤病/负面事件**
- 背景：暗夜红 `linear-gradient(160deg, #1a0a0a, #1a1a1a, #0a0a0a)`
- 标题：红色 `rgba(255,120,120,0.7)`
- 正文：暖白 `rgba(255,230,230,0.95)`
- 边框：红色半透明 `rgba(255,100,100,0.1)`
- 图标阴影：红色光晕

## 🌙 引导卡片→结局卡片 (v1.5)

### 淡入替换效果

取代 v1.4 的沉重翻转动画，改为优雅的淡入替换：

```
点击引导卡片 → 淡出(0.5s, scale 0.96) → 切换内容 → 淡入(0.6s, scale 0.96→1) → 允许滑动
```

| 阶段 | 动画 | 时长 |
|------|------|------|
| 淡出 | `fadeSwapOut`: opacity 1→0, scale 1→0.96 | 0.5s |
| 内容切换 | JS 替换背景、文字、肖像 | 0ms |
| 淡入 | `fadeSwapIn`: opacity 0→1, scale 0.96→1, translateY 8px→0 | 0.6s |

### 引导卡片增强

- 背景增加径向光晕呼吸效果 (`teaserGlow` 动画)
- 标题增加文字描边 `-webkit-text-stroke`
- 标题呼吸脉冲增加 `filter: brightness` 变化
- 底部提示文字增加上浮微动效
